## Vérifications restantes sur vrai écran ou téléphone

Rien de ce qui suit n'a été vu sur le matériel après correction, sauf mention contraire. La checklist détaillée est `docs/verification-ecran-reel.md` de nemo-pc (section « Double écran après l'essai du 15/11/2026 »).

Sur le PC, deux écrans (build avec #29 ; #32 nécessaire pour le mode test) :

- [ ] Étape « problème » d'un parcours : le 2e écran garde la couverture puis montre énoncé et documents seuls (jamais la page complète) ; l'écran principal ne montre « sur l'autre écran » qu'une fois la 2e fenêtre prête.
- [ ] Tout regrouper puis Séparer, 3 fois vite : une seule 2e fenêtre, état final = dernier clic.
- [ ] Étape suivante ordinaire : même fenêtre, rôle outils, sans boîte « Quitter le site ? ».
- [ ] Placement calé (journal « calée »), aucune bande noire visible sur un seul écran capturé ; échelles différentes (100 % / 150 %), débrancher et rebrancher un écran.
- [ ] Pause d'urgence : 2e fenêtre masquée pendant la pause, reprise au bon rôle ; limite de 2 par jour (aussi depuis le téléphone) ; créneau inchangé.
- [ ] Reprise d'une séance interrompue : durée = temps restant (au moins 10 min).
- [ ] Aucune écriture double : résultat envoyé une seule fois, page Statistiques cohérente ; consommation de Durable Objects non doublée.
- [ ] Verrou sur le lecteur : une seule indication du temps restant (celle de la page) ; barre native fine.
- [ ] Après fusion de #60 : le 2e écran ne montre plus l'ancien lecteur au premier affichage (service worker réseau d'abord) ; page de lecteur légère ; `/admin/erreurs-pages` reçoit une erreur de test.
- [ ] Après installation de #30 : accueil PC (DPI 100/125/150 %, Tab, dialogues à 150 %, clic sur l'icône, session interrompue au démarrage).

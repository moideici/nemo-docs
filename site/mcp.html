Lesoutilsdel'assistant

Claude ou ChatGPT se branchent sur /mcp du serveur. Les briefs en un appel remplacent une dizaine d'appels : l'IA reçoit le squelette de la session et n'a plus qu'à écrire le contenu.

OutilCatégorieRôle

Brancher Claude Code

claude mcp add --transport http nemo "https://nemo.moideici.tech/mcp" \
  --header "Authorization: Bearer <NEMO_TOKEN>"

Claude Desktop ou mobile : Réglages › Connecteurs › connecteur personnalisé, avec https://nemo.moideici.tech/mcp?key=<NEMO_TOKEN>.

Brancher ChatGPT

Même un compte gratuit : chatgpt.com/plugins › serveur MCP personnalisé, authentification « Aucune ». Nemo PC et l'app Android remplissent le formulaire tout seuls (« Ajouter Nemo à ChatGPT »).

Le jeton est un mot de passe. Ne le collez jamais dans un dépôt, un message de commit ou une capture. Pour relier un appareil sans le copier, utilisez le code de liaison (5 min, usage unique).
